# TITLES

- `esm-graphics-html.zip`: every graphic as an HTML browser source (unzip, add `index.html` to OBS or vMix as a
  browser source at 1920 x 1080). Live text comes from `state.json`.
- `esm-graphics.sgfx`: the same graphics as a StandBy GFX pack (Composer > Import), with live fields, In / Out
  animations and the background loop.
