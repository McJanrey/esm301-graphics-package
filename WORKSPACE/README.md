# Workspace

The full ESM show exactly as built in StandBy GFX (Chud GFX Baby): every graphic, live field, animation and asset.
To open it: install the app from the Releases page, then copy `esm/` into `C:\Chud GFX Baby\workspaces\` (new installs already include it).
`teams.json` is the team list (goes in `C:\Chud GFX Baby\library\`).
